Report a problem

Napple has no online service, so there are no player accounts to report. Problems with the software itself go to the project on GitHub.

Bugs and compatibility

Open an issue on GitHub. Say which Mac and macOS version you use, which Napple build, the game and its title id and version, and what happened. Logs from Studio's Play with Debug help a lot.

Never attach game files, keys or firmware to an issue.

Keys, game files or Nintendo code in the repository

If you think any of that is already public in the repository, do not open a public issue. Report it privately through a GitHub security advisory (the repository's Security tab, "Report a vulnerability"). The same goes for security vulnerabilities.

Rights holders

If you are a rights holder and believe something in the repository infringes your rights, use the same private channel and say what and where. It will be reviewed in good faith.
