Switch games, native on Apple Silicon.

Napple turns a game you own into a standalone Mac app. It runs the game's own ARM64 code directly on your CPU, with no emulator and no JIT.

How it works

The Switch and every Apple Silicon Mac are both ARM64. So instead of emulating the console, Napple rewrites ahead of time only the few things macOS forbids, and answers everything else in a Horizon runtime.

IngestContainers, decryption with your keys, updates and DLC.
AnalyzeLoad modules, find functions and patch sites.
ResolveMatch known signatures, fall back to reverse engineering.
RewritePatch x18, thread pointer, svc and timer registers.
PackageRuntime plus a per-game patch table, as a local .app.

What's inside

Per-game knowledge lives in data, never in per-game code branches.

Native speed

Guest code runs directly on the CPU. Nothing is interpreted or recompiled at run time.

Horizon kernel and services

Threads, scheduling, memory, IPC and a broad set of HLE services, with offline answers for online ones.

NVN to Metal

A Maxwell shader translator and NVN pipeline support, with MSAA, indirect draws and queries.

Audio and input

Audio renderer with effects and Opus over Core Audio. Controllers with rumble, plus keyboard and mouse.

Napple Studio

Drop a game on the window, watch the pipeline run, install the result.

Open compatibility data

Every game and every pipeline stage is tracked with evidence in a public matrix.

Where it stands

Napple is early. Two titles boot all the way to their title screen or early gameplay; neither is fully playable yet. Coverage below estimates the Switch platform surface the pipeline and runtime handle, not per-game compatibility.

≈ 87%overall platform coverage
100%AOT A64 rewrite
97%HLE service coverage
81%NVN API surface

Coverage is not compatibility: the long tail of command depth, shader corner cases and GPU behavior is what real games trip over first. Per-stage results are in the compatibility matrix.

Download

Builds are ad-hoc signed, not notarized. On first launch, right-click the app and choose Open. Requires an Apple Silicon Mac on macOS 26 or newer.

Legal, up front

You must own the game and bring your own prod.keys and firmware. Keys, firmware and game files are needed only at build time, and nothing is downloaded, bundled or committed. The produced app contains game-derived content and is for your personal use only; Napple does not condone sharing builds. Napple is not affiliated with or endorsed by Nintendo.
