# Animal Crossing: New Horizons (01006F8002326000)

**State:** version 3.0.3 (+3 DLC) boots through the whole opening (Timmy's dialogue, the Nook Inc. counter, the name-entry keyboard) and shows its picture through the game's own window pass (2026-10-26: `nvnProgramSetShaders` with pool-offset code addresses is accepted, see the [gfx-correctness note](../archive/changes/2026-10-26-claude-gfx-correctness-2026-10-26-macos1.md); the stopgap present is gone; Timmy and Tommy and other skinned meshes appeared once the translator read Maxwell LDC's signed immediate offset correctly); v0 (1.0.0) boots without crashes.

## What it needs
- NVN SDK 55.15 over TIPC for `sm`: refusal replies must carry the success layout with move handle 0 ([symptoms](../symptoms.md)).
- HID shared memory with even outer sampling numbers (outer = 2n).
- `IApplicationFunctions` cmd 210 event copy handle; a real clock (AdjustableUserSystemClock); `olsc:u` cmd 13; `prepo:u` 10104/10105; `SignalToAddress` type 2 value 2 and `WaitForAddress` type 3; VMNMX in the shader translator; conditional rendering evaluated at replay; command-buffer recording under one lock.
- About 19 000 tiny pre-recorded command lists at boot before the first submit.

## What is open
- iOS Simulator: 100 s, no crash, no first frame.
- v0 was not re-run after the clock/olsc/prepo/pool-race changes (its data was deleted).
- Thread 0x56 is created but never started in every boot (harmless).

## Build and test
Data as in [README](README.md#building-test-data-without-disk-pain-all-titles) with the base 3.0.3 NSP plus the update and the three DLC; a build of the 3.0.1 or 3.0.3 delta DLC set is logged in the notes folder. Headless 45 s: exit 0, 0 CRASH, about 1150-1200 frames and 24 000 draws; with scripted A presses 1738 frames in 70 s with the picture on screen. A 240 s windowed run: 7175 frames at about 30 fps, exit 0. If frames stay 0 check `NAPPLE_PCPROF=1`: thread 0x51 in sdk+0x5087xx means the HID outer-number bug.

## Numbers
- ~30 fps windowed (240 s run), 1738 frames in 70 s headless with input. Memory: not measured in a note.
