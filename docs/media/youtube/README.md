# YouTube video kit: "I didn't emulate the Switch. I changed four things."

A shootable plan for a 10-14 minute video that shows Napple on a Mac, on a TV and (honestly) on iOS, with a call to action for contributors. Docs only: no code, nothing is published from here.
Written 2026-10-27 from what the repo documents on that date; re-check the status tables before shooting because the project moves fast.

| File | What it is |
|---|---|
| [script.md](script.md) | Full shooting script: cold open, legal part, chapters with timestamps, spoken lines, VO, on-screen text, three-device sequence, honest status segment, music/sfx guidance, humor beats, sources |
| [cta.md](cta.md) | The call to action: nine asks, link placeholders, outro card, good-first-issue proposal |
| [shotlist.md](shotlist.md) | Every shot (S01-S37 plus A-roll), how to trigger it with Napple's tooling, recording and pre-flight checklists |
| [titles-thumbnails-description.md](titles-thumbnails-description.md) | 10 titles, 5 thumbnails, description with chapters and legal text, pinned comment, 5 Shorts, X thread |

Ground rules: bring-your-own game, keys and firmware (stated in the first minute and in the description); only four titles have been tested; iOS has only run in the Simulator; mods and the new render-scale options are "coming" and are never demonstrated. Back to [docs index](../../index.md).
