## 2. Offline web document kinds
- Legal information (kind 2): resolved under the title's extracted LegalInformation content, `<data-dir>/legal` or `NAPPLE_LEGAL_ROOT`. napple-build does
  not extract that content yet (see the hand-off notes), so on today's data a title's legal page is still an error exit.
- System data (kind 3, TLV 7 = system data id): the firmware archive `<data-dir>/../sysdata/<id>.bin` (the files fs.c serves to guests), extracted once by
  the new portable RomFS reader `web_romfs_extract` into `$TMPDIR/napple-web-sysdata/<id>/`, then resolved like an offline page. The firmware's
  `0100000000000804` holds the console's legal lines (`legallines.htdocs/`, 60 files); `0100000000000803` holds the browser's error templates.
- While a page is open `applet_web_html_root()` reports the root it came from, so the web sheet grants the web view read access to it (the sheet code
  is unchanged). `applet_web_open_document()` opens any offline document the HOME-menu way; `NAPPLE_OPEN_WEB_DOC=<secs>:<kind>:<id hex>:<path>`.
- **Verified**: SMO windowed, `NAPPLE_OPEN_WEB_DOC=25:3:0100000000000804:legallines.htdocs/index.html`: `web document: shown, exit reason 0, last page
  file:///.../napple-web-sysdata/0100000000000804/legallines.htdocs/index.html`; the web sheet shows the console's trademark and open-source notice page.

## 4. Frame-based scripted input
`NAPPLE_INPUT_SCRIPT` times and holds may be written `f<n>` (presented guest frames, `napple_gfx_frame_count` looked up at run time), or all plain numbers are
frames with `NAPPLE_INPUT_SCRIPT_FRAMES=1`; a frame-timed press holds 9 frames unless told otherwise. Host test `test_input_script` (16 checks).

(the log prints the frame); the third A opened the name keyboard.
