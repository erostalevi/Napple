# client-core (r12): Napple Online client core

Shared Keychain-wrapped credentials + profile map, auth/profile/social client (Rust, `crates/napple-cloud/src/online/`), the overlay function table
(`runtime/src/online/`), strong access-token/profile hooks that turn the friend service on for a signed-in Mac. Guide: `docs/guides/napple-online-client.md`.

Verified: `cargo test -p napple-cloud online` (7), `make -C runtime test-online` (27 checks), `make -C runtime GFX=napple test test-services test-ipc-reference`
green; MK8D and SMO boot headless 20 s with and without NAPPLE_NET=host, signed out, unchanged. Not verified: against the real napple-account/social
(they land in parallel items), the WebSocket stream (polling instead), the 60 s presence heartbeat from the overlay client (net_social already does it in game).
