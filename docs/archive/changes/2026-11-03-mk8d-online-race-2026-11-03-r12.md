# 2026-11-03 mk8d-online-race (r12): two MK8D instances reach the race countdown

Branch `mk8d-online-race-2026-11-03-r12`.

- **Joiner failure 2618-0502 fixed (two causes).** Found by breakpoints on the Pia connect job (`NAPPLE_DEBUG_LOG`): (1) the joiner's connect step refuses a
  station it has not heard of, so napple-online now sends a joiner a 3001 "participant joined" for every participant already in a verbose gathering, before
  its own; (2) the host's connection-request handler looks a station up by IPv4 address only, so two consoles at one address are one station and the host
  refuses the joiner. A client on the server's machine now has its own public address: runtime (`net_online.c`) puts the console address in the NAT check's
  "local IPv4" field and the socket's virtual port in the reply; napple-online (`natcheck.rs`, `server.rs`) uses both for loopback clients and the Register
  URL's own address. Needs a room (each instance a virtual address); automatic while a room's virtual LAN is up (`NAPPLE_ONLINE_NATCHECK_LOCALIP` forces it).
- **MatchmakeExtension 49** (u32 gathering id, sent when the course vote ends) is answered with the session like MatchMaking 41.
- **Result (verified):** local napple-online + napple-room, two instances in one job: both join, exchange Pia traffic (thousands of 692 / 1044-byte
  datagrams each way), reach character, kart and course vote; with frame-timed vote presses the course is selected, both players are listed and the race
  countdown starts (~215 s run). The race itself (laps, results) was not driven.
- **LDN Scan pacing:** a scan takes about 400 ms for all channels (a third for one) like the console's, instead of answering at once
  (`NAPPLE_LDN_SCAN_MS`, 0 = instant).
- `NAPPLE_NET_LOG=2` dumps the first 200 bytes of every datagram (debug aid, `net_host_sock.c`).
- Still open: the Wireless Play (LDN) joiner crash (`signal 11`, `pc=main+0x9a3c84`: a Pia job registered at menu time is zeroed before the join and
  dispatched at the join); the Friends mode list is empty; the 2618-0201 timing flake was not reproduced in about 25 pair runs.
