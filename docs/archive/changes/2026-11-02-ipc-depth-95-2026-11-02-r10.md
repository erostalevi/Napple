## What became real, by service
Each part has a test file (`runtime/tests/test_svc_*_r10*.c`). Each converted row has at least one check.
- **friend:u (43 rows, `friend_core.c`):**
  - The console's own per-user state:
    - AddPlayHistory is read back by GetPlayHistoryList, GetPlayHistoryStatistics and GetFriendCandidateList.
    - In-person (faced) requests appear in GetFriendRequestList and GetRelationship.
    - UpdateUserPresence is read back by GetUserPresenceView.
    - LoadUserSetting returns the libnx `FriendsUserSetting`, with a friend code tied to the installation.
  - Cache rows (profiles, detail, settings, relationship, blocked and invitation lists) need a network service account that the provider links. They
    answer from the provider's friend list.
  - Sync rows (Sync*, Ensure*, RequestSyncFriendList, which signals the completion event) also need `ONLINE_CAP_FRIENDS` and a connection.
  - Offline answers are unchanged: "no network service account".
- **ssl (25 rows):**
  - ISslConnection:
    - Peek is held for the next Read.
    - Poll uses the real socket readiness plus any pending decrypted bytes.
    - Verify errors come from the last handshake.
    - Options, ALPN, the DTLS descriptor, private options and the SRTP list are kept per connection.
  - ISslContext: PKI, CRL and client-certificate ids are real and can be removed.
  - The ssl certificate list rows (count, size, index, get) agree with each other. The list is empty because Napple ships no console certificate
    store.
  - With `NAPPLE_NET=host` there is no hook for the server certificate, the negotiated cipher or ALPN, so those answers are empty.
- **nifm (17 rows):**
  - A network profile store, plus the current connection as a profile built from `net_info`.
  - A real IScanRequest, which always finds 0 access points.
  - PutToSleep, WakeUp and Shutdown act on a registry of the live requests.
  - A telemetry event that fires when the connection changes.
  - IsWiredConnectionAvailable reads the provider's connection type.
- **bsd (8 rows):**
  - Real eventfd descriptors (31 and 39). They block, and they work with poll and select next to provider sockets.
  - ShutdownAllSockets(how) (40) shuts down the provider sockets.
  - The NoMem mmsg calls (42 and 43).
  - The thread core mask (200 and 201) is read back.
- **nsd (4 rows):** the application server environment type is read back and defaults to lp. GetSettingUrl copies the empty Url of the lp1
  settings.
- **sfdnsres (7 rows):** resolver options are kept per key. Query, Fetch and CancelQuery are an asynchronous form of the provider lookup.
- **fs (19 rows):**
  - fsp-srv 31, 80-88, 110, 606, 610 and 618 check the title's FS permission bits in main.npdm. Without the bit the answer is PermissionDenied.
    With it, each gets the most accurate answer this host has. 83 keeps a transfer-prohibiter count.
  - IFileSystem QueryEntry and GetFileSystemAttribute.
  - Rows 0, 37, 800 and 1001.
  - The save create commands also write the save's meta file.
- **account (5 rows after the main merge):**
  - IManagerForApplication 160 StoreOpenContext is read back by acc:u0 130 and 131.
  - 170 and acc:u0 103 return async contexts whose result follows the provider's account state. An unlinked user gets 0x1907C,
    "registration required".
  - Rows 2, 3 and 4 are napple-online's from main, kept unchanged.
- **olsc (4 rows):** async objects whose result checks, in order: network, then linked account.
- **applet (13 rows):**
  - ExecuteProgram (own index or RestartProgram) and CreateApplication*AndRequestToStart restart the running application: `execv` of the runtime on
    macOS. The user channel (121 and 122) carries over to the new process.
  - SetDelayTimeToAbortOnGpuError.
  - HDCP (170, with ICommonStateGetter 62 reading it).
  - The system button press (80) and the Home short-press message (100).
  - PrepareForJit.
  - ILibraryAppletAccessor 80.
  - SetLcdBacklighOffEnabled switches lbl's backlight state, which lbl GetBacklightSwitchStatus reads.
- **Small services:**
  - btm 1 returns the constants switchbrew documents.
  - lm 11 and its accessor: retail "success, nothing".
  - ovln GetUnreceivedMessageCount uses per-sender queues.
  - aoc 110 IContentsServiceManager and its token request (IAsyncData Get, GetSize and Cancel).
- **ldn (10 rows):**
  - Configuration rows, kept per object and checked against the switchbrew state rules.
  - Action frames.
  - The client process monitor (`ldn:u` 1): it keeps a hosted network up until the monitor is closed.
- **npns (5 rows):** Suspend and Resume with state-change events, a notification receiver, and an async token request that fails offline the way
  the console does.
- **bcat (5 rows):** the storage notifier, task suspension, system-application tasks, and the delivery list through
  `BcatProvider.read_list`.
- **prepo (2 rows):** accepted reports are kept, within the 4 MiB storage limit, and read back by ReadAllApplicationReportFiles and
  ReadAllReportFiles. ClearStorage drops them.

## Decisions and behaviour changes
- **The work was split across five sub-branches,** each in its own worktree: `claude/ipc-depth-95-r10-{net,ssl,fsacc,applet,local}`. They were
  merged here. The per-row reports are in the session notes folder (`ipc-depth-95-r10/part-*.md`).
- **Default answers that changed:**
  - The HDCP state reads 0 until the app activates HDCP (it was 2).
  - The nsd application environment type defaults to lp (1); it was 0.
  - Account and olsc network calls for an unlinked user return 0x1907C.
  - ssl GetCertificates succeeds with 0 entries.
- **New result codes** are appended to `hz_result.h`. Most are marked `[unverified]` (ssl 123/2 and 123/3, nifm 110/3400 and 110/3401, the am
  codes, acc 124/200). The friend codes are local to `offline.c`.
- **Layouts the public docs do not give** are Napple encodings marked `[unverified]` in the source. These include the friend records, prepo
  ReadAll* records, sfdnsres Query and Fetch, and EventFd flags.
- **Nothing new persists across runs:** the friend store, prepo reports and nifm profiles last for the process only.
