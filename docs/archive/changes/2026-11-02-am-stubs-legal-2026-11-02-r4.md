## 4. Network-connection library applet (NetConnect, 0x0f)
A title launches it after nifm reports a failed network request (IRequest::GetAppletInfo). It is now answered through the handler table: it finishes
normally (GetResult success) and its output storage `{u32 result; u32 pad}` carries **the "not connected" result**, the same result nifm's
GetResult gives offline here (`HZ_R_NIFM_NETWORK_COMMUNICATION_DISABLED`, 2110-1111). So HandleNetworkRequestResult keeps the request failed and
the game stays offline, as on a console that cannot connect. Before, the applet was "not implemented" and terminated with 0x1480. Layout and code are
[unverified] against a console. MK8D's Online Play reaches this applet only once nifm's GetAppletInfo (`offline.c`, ipc-reference-audit) hands out
the applet info; verification is planned at integration.
