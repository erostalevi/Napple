## Known calls (part 2)

Titles' real traces are not in the repo (no game here), so the list is "documented or standard SDK init", not a captured trace; rows were selected by command name (a name that exists in several tables of one file lists every id). `check_known_calls.py` now reads every `known_calls_*.txt` and fails when a titles row disappears, is renamed, or is `IPC_STUB` (except `vi` 0/3). 705 rows checked.
