## Findings from the new tests (open bugs, all in ac-render's files, not fixed here)
- `do_clear_tex` (mtl_replay.m) ignores the region and the channel mask (`(void)mask`): a sub-rectangle clear clears the whole texture.
- Clears are folded into the next pass; a copy/readback of that target before any draw does not flush them, so a clear after a readback reads stale (t_clear_ds, t_feedback).
- Depth clear with depth mask 0 passes; Depth16 clears agree between both paths; aliasing textures on one pool range works; presented-frame snapshot works.
